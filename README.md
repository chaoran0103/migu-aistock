# 觅股-意图选股AI平台

完整线上部署步骤见 [DEPLOY.md](DEPLOY.md)：支持 Streamlit Community Cloud 与 Docker，可配置公开访问。真实 API Key 不在交付包中，部署时在服务端 Secrets 或环境变量单独填写。

真实免费数据、可编辑条件与确定性解释；固定历史预览和个人在线筛选明确区分。股票池使用新浪HTTP，实时行情使用腾讯HTTP，最新财报使用东方财富（经AkShare），前复权日线使用腾讯HTTP。没有TCP数据源、数据库或个人筛选的磁盘行情缓存；历史展示数据按用户要求随代码固化。

## 本地运行

Python 3.10+（推荐3.12）：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

端口占用时增加 `--server.port 8520`。工作台统一使用对话选股：用户消息靠右，条件卡片直接放在对话内；只有点击卡片中的“执行筛选”才请求股票数据。

## 对话选股（当前会话上下文）

1. 输入“银行股，PE 低于 10”，得到本轮行业与估值条件。
2. 继续说“再加一个波动小”，系统展示建议门槛，请你确认，不会直接执行。
3. 回答“25%”，或点击“采用这组建议条件”。也可以明确写“波动率不超过 25%”。
4. 继续说“PE 改为 8”“删除波动率条件”，只更新提到的项，保留其他条件。
5. 核对对话内的条件卡片，点击“执行筛选”；也可点击“修改条件”展开手动编辑，再继续自然语言调整。任务仍在原后台模块执行，跨页进度与图表功能保持原逻辑。

- 当前聊天、条件、待澄清内容及最近 10 次条件变更仅存于用户会话内存；最多显示 40 条消息，模型使用最近 12 条消息和完整当前条件。没有数据库、长期记忆、用户画像或跨设备同步。
- “新对话”清空当前聊天与条件；“撤销上一步”优先取消待确认提案，否则撤销上一次条件修改。已有成功结果仍保留在结果洞察。服务器重启或浏览器会话重建可能丢失短期上下文。
- 模糊门槛、宽泛行业及互斥阈值会触发澄清。未回答必要问题、存在冲突时，对话入口的执行按钮禁用；无歧义的建议可以确认采用，必要信息缺失不能仅靠“确认”跳过。
- 支持在条件卡片中手工调整。已生效条件的修改同步到对话状态；待确认建议的修改仍需采用后才生效。后续对话以当前卡片的条件为准。
- `conversation.py` 只负责增量条件编排、短期上下文和工具返回值展示。模型输出经过白名单、Pydantic、原话及数值校验；格式不合格最多修正一次，再失败则用原规则解析器处理当前输入。没有 Key 时仍可使用常见规则与澄清流程。
- 筛选数字和候选解释来自原引擎返回值，不由模型编写。可以在对话中询问最近一次结果或具体候选入选理由。条件变更不会自动触发重新筛选。
- 页面没有“单次输入”模式或独立的条件工作台。必要澄清未完成时不能执行；条件变更后，旧结果仍可在结果洞察查看并标记为上次结果。

当前是受控的对话式选股工作流：包含意图理解、短期上下文、澄清、条件编辑、用户触发的工具执行与真实结果解释。尚未实现由模型自主选择工具、观察工具返回后继续规划的执行循环；不将聊天界面本身等同于完整自主 Agent。长期记忆不属于本项目范围，也不是 Agent 的必要条件。

本轮没有改动 `data.py`、`metrics.py`、`schema.py`、`parse.py`、`screen.py`、`explain.py` 或 `screening_jobs.py` 的逻辑；免费源降级、排序、评分和计算范围均沿用原实现。

结果洞察顶部始终提供“前往选股工作台”按钮。市场行情概览使用 `market_preview.py` 固定的真实历史行情，明确标注“此处基于历史真实数据作为可视化预览”以及数据日期、行情时点、来源和实际抓取时间；打开页面与排序均不发起网络请求。固定数据由一次完整的新浪股票池及腾讯快照抓取自动生成，保留5,223只股票的实际数字，不用于个人筛选。更新预览需重新抓取并重新生成该文件，不假装自动更新为实时行情。

执行个人筛选时会创建当前会话独立的后台任务，重新在线取数。切换工作台、结果洞察或设置不会中断任务，也不会重复提交。结果洞察上方显示“正在执行筛选”与进度，历史预览始终在下方。成功后个人结果和CSV导出按钮显示在历史预览上方；无候选、失败、导出或再次筛选均不会移除历史预览。页面每秒轻量检查任务状态，工作线程不调用Streamlit。任务保存在当前进程的会话内存；服务器重启或会话重建不保证任务恢复。

发送对话后，输入框下方显示旋转圆圈和理解提示，结束后自动移除。执行筛选后，对话内显示旋转圆圈、当前进度与每秒更新的已用时；切换页面继续筛选。

无Key时按当前输入逐条规则解析，不再加载固定模板。有兼容LLM时由模型拆解；模型异常也只回退到当前输入的规则解析。无法识别或免费源不支持的片段逐条提示，不擅自替换成经营改善等旧条件。模糊高低要求的数值门槛是建议值，会标记需要人工确认。

例如“银行股，PE低于10”只产生银行行业和PE条件；“近半年涨幅超过20%，市值100亿以上”产生ret_120和总市值条件；“经营改善、估值合理，芯片行业”产生经营改善、PE-TTM和半导体行业，不附加波动率。

## 研究仪表盘与交互

“觅股-意图选股AI平台”使用上海城市背景、白色内容框与黑色操作按钮，卡片、标签和图表统一黑白灰配色。左侧可切换选股工作台、结果洞察、数据与设置；窄屏可用左上角箭头收起侧栏。

- 工作台初始展示聊天欢迎语与输入框；后续根据对话增量更新内嵌条件卡。点击“修改条件”展开编辑，添加指标不预选任何默认指标；不会自动加入经营改善、PE或波动率。“查看原话与条件映射”和设置页的“不支持指标”列表已移除；具体无法执行的要求仍会在解析时说明。
- 执行后显示候选散点图与行业环图。横纵轴可切换，支持悬停看数值、滚轮缩放和拖动；极值较大时可启用对称对数刻度。
- “筛选过程”提供逐步漏斗图及可切换条件的三档敏感性柱图；原始数据可展开核对。
- “差一点入选”保留实际差距和阈值建议；候选可逐只选择查看真实指标解释，并导出 CSV。

图表来自真实 HTTP 行情或用户已执行的筛选结果，不生成示意行情。图表交互不联网、不改变筛选条件；工作台修改条件后需重新执行，洞察页会标明仍在展示上次结果。页面样式在 `assets/theme.css`，图表组件在 `ui.py`，均需随应用一起部署。`conversation.py` 管理对话编排，`screening_jobs.py` 管理后台任务；不需要额外服务。

全站使用用户提供的上海天际线原图 `assets/shanghai-skyline.png`，随代码部署，无需外部图片服务。大标题与步骤标题以白字直接叠在压暗的背景上，正文放在白色底板内；导航、操作按钮、条件标签和数据卡片保留圆角，悬停时轻微浮起并高亮；系统启用减少动态效果时取消位移。样式调整不影响模型调用，API Key 始终仅留在服务端。

## 自然语言与指标范围

有兼容LLM时，行业、盈利、估值、市值、价格、动量、波动和回撤意图可以映射到注册指标。无法映射的偏好会警告并降级，绝不承诺任意想法都有对应数据。资产负债率、商誉、机构持仓、北向资金、分红率、未核实的52周高低价不支持；近似条件需要明确说明并标为低置信度。没有行业中性化。

连接信息仅由服务端的环境变量或 Streamlit Secrets 管理。页面只显示模型名称和配置状态，不创建 API Key 输入框，不提供显示/复制密钥按钮，也不把密钥值发送给浏览器。接口地址同样不能由页面改写。三个环境变量如下：

```bash
export LLM_BASE_URL='https://your-provider.example/v1'
export LLM_API_KEY='your-key'
export LLM_MODEL='your-model'
```

DeepSeek 可配置 `LLM_BASE_URL=https://api.deepseek.com`、`LLM_MODEL=deepseek-flash`（已按[官方说明](https://api-docs.deepseek.com/)与模型接口验证）。本机私有配置可保存在 `.streamlit/secrets.toml`，该文件已在 `.gitignore` 排除，不能进入代码包或公开仓库。部署时在 Cloud Secrets 单独配置，不依赖本机文件。Key 仅提交给指定模型接口；LLM 将想法拆解为查询指标，腾讯/新浪/东财 HTTP 返回真实数据，模型不编造股票数据。模型请求优先直连，仅连接故障时尝试系统代理。

条件JSON使用注册表白名单与Pydantic校验。比例指标在IR中使用小数；财报同比、换手率等以百分数保存。净利润金额 `np_value` 单位为元，是带正负号的原始利润金额，不是取数学绝对值。

## 执行时在线取数

- 数据日期不写死。行情时点取腾讯响应时间戳；节假日会如实显示最近交易日，不把旧报价标成今天。
- 自动从已经结束的最近季度向前探测，直到取得六个非空报告期；同公司同报告期按最新公告日去重，行业取最近非空值。
- 新浪沪深代码池排除ST/退市标记。新股过滤采用“最新财报存在且至少两期历史财报”，**仅是近似，不保证上市满一年**；财报不可达时无法执行该过滤，漏斗及警告会明确显示跳过。
- 每次点击执行使用 `DataClient(force_refresh=True)`：重新请求新浪股票池、腾讯快照、六期财报及当前条件需要的日线，绕过模块缓存，不使用Streamlit数据缓存。固定历史概览单独读取代码内的真实历史记录，不发起网络请求，且不参与个人筛选。
- 一次执行内部绑定本轮在线取得的快照，避免重复请求与混用时点。洞察页保留最近一次成功结果供阅读，这不是下一次执行的数据缓存。**每次执行需要联网**；失败时工作台提示失败，洞察页仍明确标注上次成功结果与原数据时点，不冒充本次结果。旧版本 `data_cache/` 不再读取。
- 在线全市场取数可能需要数分钟；逐只日线会额外增加耗时。实时请求指每次向数据源获取其最新返回值，不代表财报实时更新：行情可能延迟，财报按报告期披露，日线按交易日更新。节假日仍显示实际最近交易日。
- 启动探针打印指定三只样本的全部88字段、确认映射和未知索引。未知字段不用作指标。免费接口无稳定字段契约，发生变化可能导致指标缺失。

## 两阶段筛选及降级

只执行当前IR中的条件与对应守卫。PE>0与经营改善的利润>0守卫仅在使用相应指标时启用。具体行业在执行后与本轮在线财报核对；未匹配时要求修正，不悄悄放宽行业条件。只有存在日线指标时才进入阶段B、按上限截断；默认150只，可调50–400。**走势仅计算初筛后的前N只，不是全市场**，near-miss不拉日线。

腾讯前复权close计算收益率。波动率、最大回撤最近252根，不足252但至少200根用实际值；不足200不进入最终结果。MA250使用600自然日窗口，分母=有效根数−249，至少60根才计算占比。动量 `ret_20/60/120 = close[-1]/close[-(N+1)]-1`；评估窗口可能短于全年。没有走势条件时不请求日线、不做日线有效性过滤，也不应用走势候选上限。

腾讯若返回限流或访问校验页，会暂停新增日线请求5分钟，不绕过校验、不用未复权日线冒充前复权。应用不会拿旧日线缓存替代本次请求。缺失数量和剔除数会显示在结果中；暂停期结束后可重试。这也可能导致某次筛选无候选，不能保证免费源在云端始终可用。

软条件采用连续评分，缺失项权重从分母剔除；无任何有效软条件时分数为空。敏感性只根据当前数值型硬条件生成三档，并含对应守卫；数量是单项独立通过数。near-miss建议仅保证通过阶段A，仍受候选截断和走势硬条件约束。

东财不可达时应用可启动：跳过财务类条件及行业筛选，并逐项警告；保留腾讯估值/行情和日线条件。**降级结果不代表原意图全部满足。**新浪或腾讯基本行情不可用则无法构造可信股票池，会显示错误而不造数据。

## Streamlit Community Cloud 部署

1. 将本包完整代码（含 `conversation.py`、`screening_jobs.py`、`market_preview.py`、`ui.py`）、整个 `assets/`、`requirements.txt`、`.streamlit/config.toml` 推到自己的GitHub仓库。不要上传 `.venv`、旧数据缓存、`outputs`、`work` 或密钥。
2. 在 Streamlit Community Cloud 选择 **Create app**，选择仓库、分支，入口填 `app.py`，Python推荐3.12。
3. 在 **Advanced settings → Secrets** 中可填写以下TOML（均可省略）。应用同时支持本地环境变量与Cloud Secrets：

```toml
LLM_BASE_URL = "https://your-provider.example/v1"
LLM_API_KEY = "your-key"
LLM_MODEL = "your-model"
```

4. 点击 **Deploy**，并在应用分享/访问设置允许公开访问。用无痕窗口验证其他用户无需你的账号即可使用。海外服务器如果仅东财不可达，会自动进入上述降级模式；免费数据源仍可能限流或屏蔽其他接口。

免费托管平台可能在闲置后休眠，具体时长和资源限制以平台当前说明为准。冷启动涉及依赖安装及首轮数据请求，不保证1分钟就有筛选结果。参见[官方应用管理与休眠说明](https://docs.streamlit.io/deploy/streamlit-community-cloud/manage-your-app)和[部署步骤](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app)。本交付提供部署包，未发布线上站点。

```bash

```

仅供研究学习，不构成投资建议；数据为免费源，可能延迟或缺失。
